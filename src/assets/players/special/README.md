# special ── 状態を表す印（PHASE 4.7）

置くもの: `special_<状態>_001.png`

| ファイル | 出る場面 |
| --- | --- |
| `special_injury_001.png` | 怪我で離脱中 |
| `special_fatigue_001.png` | 疲労78以上 |
| `special_slump_001.png` | スランプ |
| `special_hot_001.png` | 絶好調 |
| `special_rookie_001.png` | 今季デビュー |
| `special_veteran_001.png` | 36歳以上 |

肖像のいちばん上に、小さく重なります。
顔を隠さない大きさ（キャンバスの1/4以下）にしてください。

**ゲームの状態から見た目が決まります。逆はありません。**
ここに素材を置いても、ゲームの判定は1つも変わりません。

素材が無ければ何も描かれません（欠けていてもゲームは壊れません）。
