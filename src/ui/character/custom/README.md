# ここに、あなたが描いたSVGを置きます

置けば入ります。登録の作業はありません。

```
custom/head/head_06.svg      → 頭の6番目として使われる
custom/cap/cap_06.svg        → 帽子の6番目として使われる
```

フォルダ名が種類です。ファイルの中の `data-category` と揃えてください。

* 下書きを作る … `npm run character:template`
* 確かめる     … `npm run character:check`
* 見る         … `npm run character:workshop`
* 手順の全部   … `character-template/README.md`

読めないファイルがあっても、ゲームは止まりません。
そのファイルだけ飛ばして、理由を Workshop に出します。

**このフォルダは空のまま始まります。** 中身はあなたが描くものです。
