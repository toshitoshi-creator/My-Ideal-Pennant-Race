# CHARACTER CREATION TEMPLATE

**あなたがキャラクターを描くための制作環境です。**

ここに絵は入っていません。枠と目印と道具だけです。
12枚のSVGはすべて空の状態から始まります。中身はあなたが描きます。

生成AIは使いません。外部から画像も取ってきません。

---

## 3つのコマンド

```bash
npm run character:template        # 空のテンプレートを作る（描いたものは上書きしません）
npm run character:preview         # 12枚を重ねて確認するページを作る
npm run character:template:check  # 決まりを守れているか検査する
```

`npm run character:preview -- --watch` にすると、SVGを保存するたびに作り直します
（ページ自体は自動で更新しないので、保存後にブラウザを再読み込みしてください）。

---

## キャンバス

12枚すべて**完全に同じ**です。ここが揃っていることが、重ねたときに位置が合う唯一の理由です。

```
width   256
height  320
viewBox 0 0 256 320
```

`300×300` や `512×512` や `1024×1280` にしないでください。
パーツごとに違うサイズにするのも禁止です。

```
CENTER_X       128    中心線

HEAD_TOP        44    頭のてっぺん
BROW_LINE      110    眉
EYE_LINE       125    目
NOSE_LINE      152    鼻
MOUTH_LINE     177    口
CHIN_LINE      207    あご
NECK_LINE      227    首
SHOULDER_LINE  262    肩
```

`GUIDE.svg` にこの線が引いてあります。制作中の目印で、**ゲームでは使いません**。

これは**描き始めるときの目安**です。
完成したパーツの座標を、あとから勝手に補正するためのものではありません。

## 守ること

### 1. viewBox を変えない

`0 0 256 320` のままにしてください。ここが違うと、重ねた瞬間にずれます。

### 2. 背景を描かない

```xml
<rect width="256" height="320" fill="white"/>   <!-- 禁止 -->
```

背景は完全透明のままにしてください。

### 3. `<g>` の中に描く

```xml
<g id="layer-04-head" data-layer="04_head">
    <!-- ここに描く -->
</g>
```

この外に描いたものは、レイヤーとして扱われません。

### 4. 位置は自分で合わせる

**自動で中央に寄せたり、拡大縮小したり、位置を補正したりはしません。**

これは意図的です。自動補正でずれを隠すと、
「なぜかずれている」が原因不明のまま残り続けます。
ずれたら、描いた側の座標を直してください。preview でどこがずれているか見えます。

### 5. 外から取ってこない

`<image>` / base64画像 / 外部URL / `<script>` は入れないでください。
検査で止まります。

### 6. 線を細くしすぎない

`stroke-width` は **1.5以上**を目安に。スマートフォンで潰れます。
`vector-effect="non-scaling-stroke"` を併用してください。

## 制作の手順

一気に作らず、1枚ずつ確認しながら進めてください。

```
STEP 1   04_head        顔の輪郭      ← ここが全部の基準
STEP 2   03_ears        耳
STEP 3   06_eyes        目
STEP 4   07_eyebrows    眉
STEP 5   08_nose        鼻
STEP 6   09_mouth       口
STEP 7   05_hair_back   後ろ髪
STEP 8   10_hair_front  前髪
STEP 9   02_neck        首
STEP 10  01_body        ユニフォーム
STEP 11  11_cap         帽子
STEP 12  12_details     細部
```

各STEPのあとに `npm run character:preview` で重ねて確認してください。

preview では、

* レイヤーを1枚ずつ ON/OFF できます
* 「順に足す」を押すと、顔→耳→首→体→…と重なっていくのが見られます
* GUIDE と 10px グリッドを重ねられます
* 各レイヤーの **bounding box**（left / top / right / bottom / 中心）が出ます
* 390×844（スマートフォン）の大きさで確認できます

**頭・耳・髪・帽子の接続位置**は、bounding box の数字で見比べるのがいちばん確実です。

## パーツを増やす

同じ256×320で描けば、差し替えるだけで同じ位置に出ます。

```
10_hair_front.svg      いま使っているもの
hair_front_01.svg      予備
hair_front_02.svg
hair_front_03.svg
```

使いたいものを `10_hair_front.svg` に置き換えてください。
描画のコードを直す必要はありません。

---

## 色

いまは**形と位置を最優先**にしてください。色はあとから変えられます。

基本色は5つです。

```
SKIN     肌
HAIR     髪
LINE     輪郭線
UNIFORM  ユニフォーム
CAP      帽子
```

制作テンプレートでは色を固定しすぎません。
ゲームに載せる段階で、選手ごとの肌の色・球団色に差し替えられる形にします。

---

## 検査

```bash
npm run character:template:check
```

見るのは「決まりを守れているか」だけです。
**絵の良し悪しは判定しません。** そこはあなたが決めることです。

| 印 | 意味 |
|---|---|
| ○ | 問題なし |
| △ | 使えますが、気になる点があります |
| × | このままでは重ねたときに壊れます |

---

## ゲーム本体との関係

この制作環境は**ゲームのロジックから完全に分離**しています。

試合シミュレーション・選手能力・成績・年俸・CPU AI・乱数・セーブデータ・
`SAVE_VERSION`・シーズン処理・ドラフト・FA・トレードは、いっさい触りません。

なお、ここの基準座標（`EYE_LINE 125` など）は、
**いまゲームの中で動いている基準線とは別の値**です。
描き上がったパーツをゲームに載せるのは、絵ができてからの作業になります。
