# 手描きパーツの仕様

選手の絵を、パーツごとに手で描くための仕様です。

生成AIは使いません。あなたが描いたものを、**1画素も動かさずに**取り込みます。

---

## 1. 共通のきまり

| | |
| --- | --- |
| キャンバス | **1024 × 1280**（縦長）。すべてのパーツで同じ |
| 形式 | **透過PNG**。JPEG は不可 |
| 背景 | **完全に透明**。白も灰色も塗らない |
| 位置 | 下の基準線に合わせて、**そのキャンバス上の正しい場所に描く** |
| 端 | 画面の端に接しない |
| 色 | 球団色を塗らない（ゲーム側で塗ります） |

**位置がいちばん大事です。** パーツは重ねて1人の選手になるので、
目だけ、口だけを描いた絵でも、1024×1280 の中の「顔のその場所」に描いてください。
取り込みのときに位置は直しません。描いたとおりに重なります。

---

## 2. 顔の基準線

キャンバス 1024×1280 の上の座標です。

```
  y=210 ┌──────────────────┐  髪の生え際
        │                  │
  y=428 │   ●●      ●●     │  眉        （左 x=404 / 右 x=620）
  y=496 │   ◕        ◕     │  目        （左 x=408 / 右 x=616）
  y=512 │ (             )  │  耳        （左 x=250 / 右 x=774）
  y=600 │        ▲         │  鼻        （中心 x=512）
  y=712 │       ▂▂▂        │  口        （中心 x=512）
  y=800 │        ‿         │  あご
  y=856 │      ┌───┐       │  首のつけね（中心 x=512）
        │   ┌──┴───┴──┐    │  肩        （左 x=236 / 右 x=788）
 y=1280 └──────────────────┘
```

顔の横幅は **x=244 〜 780**。左右の中心はいつも **x=512** です。

## 4. 重なる順番

小さいほど下（先に描かれる）です。

```
 2 姿勢       10 眉
 3 体         11 目
 4 ユニフォーム 12 鼻
 5 首         13 口
 6 耳         14 ひげ
 7 頭         15 髪
 9 あご・頬    16 帽子
             17 眼鏡
             19 表情
             20 状態
```

耳は頭より**下**、髪は頭より**上**です。

---

## 5. 色について

**肌と髪は色を塗り分けなくて構いません。**

- 頭・体 … 中間の肌色ひとつで描いてください。取り込みのとき **8色**に振り分けます
- 髪・後ろ髪 … 中間の暗い色ひとつで描いてください。**10色**に振り分けます

明るさの差（陰影）はそのまま活きます。色相だけが置き換わります。

**球団色は塗らないでください。** ユニフォームと帽子はオフホワイトのままにして、
球団の色はゲーム側で乗せます。

## 6. 取り込みかた

```
npm run assets:import              全部まとめて
npm run assets:import -- --type eyes   目だけ
```

取り込みでは、こう動きます。

1. **確かめる** … 1024×1280 か / 透明か / 端に接していないか / 基準点に近いか
2. **そのまま置く** … 位置は動かしません
3. **増やす** … 派生サイズ（512 / 256 / 128）と、肌8色・髪10色

そのあと、

```
npm run assets:manifest    目録を作り直す
npm run assets:validate    仕様に合っているか調べる
npm run assets:gallery     並べて目で確かめる
```

---

## 7. 少しずつ進められます

全部そろうまで待つ必要はありません。

素材が足りないうちは、ゲームは **PHASE 4.5 の SVG** で選手を描きます。これは異常ではなく、
そう作ってあります。必要な種類（頭・髪・眉・目・鼻・口・体・ユニフォーム）が
そろった時点で、自動的に画像で描くようになります。

1種類ずつ描いて `assets:import` して `assets:gallery` で確かめる、
という進め方ができます。
