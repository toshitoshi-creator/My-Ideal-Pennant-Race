# 選手ビジュアル素材の作りかた

このフォルダは **画像を作る人のための資料** です。
ゲーム本体はここのファイルを一切読みません。ビルドにも含まれません。

素材は外部の画像生成AIで作りますが、**ゲームがAIを呼ぶことは絶対にありません**。
できあがった画像ファイルだけを `src/assets/players/` へ置き、ビルド時に同梱します。
APIキーは要りません。`.env` も要りません。外部サービスが止まってもゲームは動きます。

## ファイルの案内

| ファイル | 中身 |
| --- | --- |
| `style-bible.md` | 全素材に共通する絵柄の決めごと。**最初に読む** |
| `negative-prompt.md` | すべての生成で必ず付けて外すもの |
| `canvas.md` | 共通キャンバスと基準点。ここがずれると顔が組み上がらない |
| `01-head.md` … `18-pose.md` | 種類ごとの、そのまま貼れるプロンプト |
| `workflow.md` | 生成 → 加工 → 取り込み → 検査 の手順 |

## 早わかり

```
1. style-bible.md と negative-prompt.md を読む
2. 種類ごとのファイルからプロンプトをコピーして生成する
3. 背景を透明にし、1024x1280 に合わせる（workflow.md）
4. src/assets/players/<dir>/ へ規則どおりの名前で置く
5. npm run assets:manifest
6. npm run assets:validate     ← ここが PASS になるまで取り込まない
7. npm run gallery             ← 目で見て確かめる
```

素材が1枚も無くても、途中まででも、ゲームは壊れません。
必要な種類がそろうまでは PHASE 4.5 の SVG がそのまま使われます。
