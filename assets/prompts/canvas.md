# CANVAS ── 共通キャンバスと基準点

すべての素材は**同じ大きさ・同じ位置**で描きます。
だから重ねるだけで顔が組み上がり、ゲーム側は位置合わせを一切しません。

## キャンバス

| | 値 |
| --- | --- |
| ゲーム同梱 | **1024 × 1280 px** |
| マスター（作業用） | 2048 × 2560 px（縦横ちょうど2倍） |
| 背景 | 完全な透明 |
| 形式 | マスター PNG / 同梱 WebP |

生成AIは 1024×1280 を直接出せないことがあります。
その場合は 1024×1024 で作り、上下に透明を足して 1280 にします（`workflow.md`）。

## 基準点（1024×1280 上の座標）

`config/visual-assets.json` の `anchors` と同じ値です。**こちらを直したら向こうも直す。**

```
                 x=512（中心線）
                   │
   y=210 ─────── 頭のてっぺん
   y=306 ─────── 帽子のつば
   y=428 ─────── 眉の高さ        左 x=404 / 右 x=620
   y=470 ─────── 顔の中心
   y=496 ─────── 目の高さ        左 x=408 / 右 x=616
   y=512 ─────── 耳の高さ        左 x=250 / 右 x=774
   y=600 ─────── 鼻
   y=712 ─────── 口
   y=740 ─────── ひげの中心
   y=800 ─────── あご先
   y=856 ─────── 首の付け根
   y=980 ─────── 用具の中心
```

顔の横幅は x=244 〜 x=780、肩幅は x=236 〜 x=788 に収めます。

## 確かめかた

作った素材を1枚、`head_001` の上に重ねてみます。
基準点がずれていれば、目が額に乗る・口があごから外れる、で一目でわかります。
`npm run gallery` は組み上げた結果を並べて見せるので、ここで確認します。

## よくあるずれ

| 症状 | 原因 |
| --- | --- |
| パーツ全体が小さい | 1024×1024 で作って、上下に足さず引き伸ばした |
| 顔が左右にずれる | 生成AIが人物を中央に置かなかった。切り直す |
| 目だけ高い | 目の高さ 496 ではなく画像の中央に描いた |
| 髪が頭に食い込む | 頭のてっぺん 210 より下から描き始めた |
