# STYLE BIBLE ── 絵柄の正本（PHASE 4.7）

**この1枚がデザインの基準です。生成された画像がデザインを決めるのではありません。**

生成AIは、頼めば何かを返してきます。返ってきた絵が良く見えたからといって、
それに合わせて基準を動かしてはいけません。基準はここで、絵のほうが従います。
ここから外れた素材は、どれだけ単体で良く見えても不採用にします。

---

## 1. ひとことで言うと

> **フラットなベクターのアバターアイコン。**

太い黒の輪郭線、べた塗り、記号のように単純化された顔。
アプリのプロフィール画像のような、はっきりした絵柄です。

### 目指すもの

- 太く均一な黒い輪郭線
- 完全にフラットな塗り（グラデーションなし）
- 陰影は最小（1つの面につき多くて2階調）
- 顔の造作は**記号**として描く（目は角丸の形、眉は線、口は1つの形）
- 明るくはっきりした色
- 頭はやや大きめ。親しみのある頭身
- 48pxまで縮めても形が分かる

### 目指さないもの

- 写実的な描き込み
- 塗り込み・エアブラシ・柔らかい陰影
- 肌の質感・毛穴・しわ・髪の毛1本1本
- 3DCG風・写真風
- まつげ・歯・鼻の穴などの細部

---

## 2. なぜこの絵柄なのか

**部品に分けられるからです。**

写実に寄せると、生成器は「1枚の完成した肖像」を描こうとして、
「髪だけ」「目だけ」という頼みを聞きません。実際に試して、そうなりました。

記号的な絵柄なら、

- 形が単純なので、部品として切り出せる
- 太い輪郭線があるので、背景から綺麗に抜ける
- べた塗りなので、色を差し替えても破綻しない
- 重ねたときに馴染む

という利点があります。**絵の好みではなく、組み立てられるかどうかで選んでいます。**

---

## 3. 線

| 項目 | 決めごと |
| --- | --- |
| 太さ | 太い。1024px 基準で 12〜16px |
| 抑揚 | 完全に均一 |
| 色 | 黒（`#000000` に近い） |
| 端 | 必ず閉じる。開いた線は作らない |
| 内部線 | 外形と同じ太さ。細い描き込み線は使わない |

**線の太さが変わると、重ねたときにすぐ分かります。** ここは絵の上手さより優先します。

---

## 4. 陰影

- **1階調**が基本。多くて2階調
- 境目はくっきり。ぼかさない
- 落ち影は描かない
- 光沢・ハイライトは入れない（目の光も不要）

---

## 5. 色

| 用途 | 目安 |
| --- | --- |
| 輪郭 | 黒 |
| 肌 | 明るいオレンジ寄りの肌色。8段階 |
| 髪 | はっきりした色。10段階 |
| ユニフォーム地 | 生成りの白 `#f2efe6` |

彩度は抑えすぎません。アイコンとして見えることを優先します。

### 髪と肌は「形だけ」作る

髪色と肌色は素材に焼き込まず、後処理で振り分けます。
AIに10回頼むと形がぶれるうえ、費用も10倍かかります。

### 球団色は絶対に焼き込まない

ユニフォームも帽子も生成りの白だけ。球団色はゲームが細い線として重ねます。

---

## 6. 顔の個体差

**300〜800人が並びます。「みんな同じ顔」がいちばんの失敗です。**

だから、パーツごとに**構造そのものが違う**ものを用意します。

| 部品 | 変えるもの |
| --- | --- |
| 顔の輪郭 | 縦横比・あごの角度・頬骨の張り |
| 目 | 形・開き・まぶた・左右の間隔・傾き |
| 眉 | 太さ・角度・長さ・位置の高さ |
| 鼻 | 鼻梁の高さ・小鼻の広さ・先端の形 |
| 口 | 唇の厚み・幅・口角の向き |
| 耳 | 大きさ・張り出し・耳たぶ |
| あご | 幅・割れ・たるみ |
| 体格 | 肩幅・胸の厚み・全体の量感 |

**やってはいけないこと**：同じ形の色違いを「10種類」と数えること。
髪なら短髪・七三・オールバック・くせ毛・後退…と、**形が違う**ものを並べます。

---

## 7. 年齢

同じ人が年を取るのであって、**別人になってはいけません**（§22）。

| 段階 | 年齢 | 変わるもの |
| --- | --- | --- |
| YOUTH | 〜22 | ひげがほぼ無い |
| PRIME | 23〜27 | 基本の形 |
| MATURE | 28〜31 | ひげが出やすい／表情に厚み |
| VETERAN | 32〜35 | 白髪が出はじめる／生え際が上がる |
| ELDER | 36〜 | 白髪が増える／輪郭がゆるむ |

**変えないもの**：目・鼻・口・耳・骨格。ここを変えると別人になります。

---

## 8. 表情

表情は**ゲームがすでに決めた状態を映すだけ**です（§23）。
表情が状態を決めることは絶対にありません。

```
怪我      → injured
スランプ  → disappointed
疲労      → tired
絶好調    → confident
好調      → focused
優勝・受賞 → happy / celebrating
それ以外  → neutral
```

表情素材は「眉・目・口」だけを描き、顔の上に重ねます。
顔の造作は動かしません。

---

## 9. パーツとして描く

**いちばん大事な決まりです。**

AIに「選手の顔」を描かせてはいけません。**部品だけ**を描かせます。

| 作るもの | 描いてよいもの | 絶対に描いてはいけないもの |
| --- | --- | --- |
| 頭 | 額からあごまでの肌 | 目・眉・鼻・口・耳・髪 |
| 髪 | 前髪・もみあげ・頭頂 | 顔・額の肌・耳 |
| 目 | 左右一組のまぶたと黒目 | 眉・鼻・顔 |
| 眉 | 左右一組の眉 | 目・顔 |
| 鼻 | 鼻だけ | 顔・口 |
| 口 | 閉じた口だけ | 顔・鼻・ひげ |
| 耳 | 左右一組の耳 | 頭・髪 |
| 体 | 肩から胸 | 首・頭・ユニフォーム |

「その素材を、まったく違う10人に重ねても成立するか」で判断します。
成立しないなら、描き込みすぎです。

---

## 10. 置き方

- 必ず**真正面**。横顔・斜めは作らない
- 傾けない
- 背景は**完全に透明**
- 共通キャンバス **1024 × 1280**（`canvas.md`）
- 基準点に合わせる（後処理が直しますが、近いほど品質が上がります）

---

## 11. 禁止（§9）

法律と礼儀の問題なので、例外はありません。

- 実在の選手・監督・有名人に似せる
- 実在球団のロゴ・マーク・ユニフォームの意匠
- 既存ゲーム・アニメのキャラクターに似せる
- 特定のイラストレーターの作風の完全な模倣
- ブランドロゴ・透かし・署名・文字・数字
- 背景・UI・枠・影
- 写真風・3D風
- 低品質なクリップアート
- 奇形・余分な手足・不自然な目
- 特定の国・人種の戯画化（肌の8段階は連続した見本として扱う）
- 未成年に見える造作（17〜45歳の範囲で作る）

機械で見つけられるのは背景と大きさだけです。
文字・ロゴ・似せすぎは **`npm run assets:audit` で人が1枚ずつ見て** 落とします。

---

## 12. 採否

| 点数 | 判定 | 扱い |
| --- | --- | --- |
| 80以上 | APPROVED | 採用してよい |
| 60〜79 | REVIEW | 人が見て決める |
| 59以下 | REJECT | 作り直す |

機械の点数が満点でも、**人の確認が済むまで採用しません**。
点数は「明らかにおかしいものを弾く」ためのもので、良し悪しは測れません。

---

## 13. 迷ったとき

3つの問いに戻ります。

1. **300人並べたときに、同じ顔が2つ出ないか**
2. **他の素材と、線の太さと陰影の段数がそろっているか**
3. **重ねたときに、線が二重にならないか**

3つとも「はい」なら採用です。
1つでも「いいえ」なら、単体でどれだけ良く見えても作り直します。

---

## 14. 生成器に部品を描かせるときの注意

**「髪の素材」と頼むと、生成器は親切に顔まで描きます。**

実際に GPT Image で3通り試しました。

| 頼み方 | 結果 |
| --- | --- |
| 「頭に載る髪。頭は描かないで」 | 髪＋顔の輪郭＋耳を描いた |
| 上に「顔の輪郭線を描くな」を追加 | あごの線がまだ残った |
| 「物としてのウィッグ」 | 顔の穴が無い、髪の塊になった |

一方で、**頭（造作なし）は一発で指示どおりに出ました。**

つまり「まわりの形が要らない部品」（頭・体・帽子・用具）は分けられますが、
「頭にくっついているもの」（髪・眉・目・耳）は分けにくい、ということです。

素材を作る前に、この点を踏まえて設計を決めてください。
