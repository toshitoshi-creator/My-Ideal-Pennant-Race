# STYLE BIBLE ── 絵柄の正本（PHASE 4.7）

**この1枚がデザインの基準です。生成された画像がデザインを決めるのではありません。**

生成AIは、頼めば何かを返してきます。返ってきた絵が良く見えたからといって、
それに合わせて基準を動かしてはいけません。基準はここで、絵のほうが従います。
ここから外れた素材は、どれだけ単体で良く見えても不採用にします。

---

## 1. ひとことで言うと

> 現代的なスポーツマネジメントゲームの、上質な2Dキャラクターイラスト。

**紙面のようなUIの上に、丁寧に描かれた人物が置かれている。**
これがこのゲームの狙いです。UIは紙、人物はイラスト。この差が効きます。

### 目指すもの

- 洗練されたスポーツゲームの選手イラスト
- 選手名鑑・スポーツカードの肖像
- 現代的な2Dキャラクターアート
- 漫画的だが、子供向けではない
- 簡潔だが、ディテールがある
- 長く見ていて飽きない

### 目指さないもの

- アイコン／ピクトグラム
- クリップアート
- のっぺりした塗り絵
- 写真そっくり
- 3DCG風
- 極端なデフォルメ（頭身を崩さない）
- 「いかにもAIが描いた顔」

---

## 2. 立ち位置

写実とアニメのあいだ、**写実寄りの様式化**に置きます。

```
写真 ────────── ここ ────────── アニメ ────── デフォルメ
                  ↑
        骨格は本物らしく、
        表現は絵として整理する
```

- 骨格・比率は成人として自然に。頭身を崩さない
- 皮膚の質感・毛穴・産毛は描かない
- 目は人間の目の構造を保つ。極端に大きくしない
- 陰影は「面」で捉える。写真のような連続階調にしない

---

## 3. 線

| 項目 | 決めごと |
| --- | --- |
| 太さ | 1024px 基準で 5px。全パーツで同じ |
| 抑揚 | ほぼ均一。筆圧の変化は付けない |
| 色 | 純黒にしない。濃い墨色 `#1b1a17` |
| 端 | 開いたままにしない。輪郭は必ず閉じる |
| 内部線 | 外形より細く（3px）。鼻・耳・あごの示唆に使う |

線が太さを変えると、パーツを重ねたときに「切り貼り」に見えます。
**線の太さの統一は、絵の上手さより優先します。**

---

## 4. 陰影

- **2〜3段階**まで。連続したグラデーションは使わない
- 光源は常に **左上45度**。全パーツで固定
- 落ち影（床・体に落ちる影）は描かない。重ねると濁る
- 反射光・環境光は入れない
- 光沢・ハイライトは、目に1点だけ

---

## 5. 色

UI の「紙とインク」に寄せて、彩度を抑えます。

| 用途 | 目安 |
| --- | --- |
| 輪郭 | `#1b1a17` |
| 影 | 地の色に墨を 12〜20% 混ぜた色 |
| ユニフォーム地 | 生成りの白 `#f2efe6` |
| 彩度 | どの色も HSV の S が 60% を超えない |

### 髪と肌は「形だけ」作る

**髪色と肌色は素材に焼き込みません。**

AIには中間色の髪・中間色の肌で形だけ作らせ、
色は後処理（`npm run assets:process`）で振り分けます。

理由：

- 同じ形のまま10色そろう。AIに10回頼むと形がぶれる
- 費用が10分の1になる
- あとから色を足せる

髪10色・肌8段階の実際の値は `scripts/assets/pipeline.ts` の
`HAIR_RAMPS` / `SKIN_RAMPS` にあります。

### 球団色は絶対に焼き込まない

ユニフォームも帽子も生成りの白だけで作ります。
球団色はゲームが細い線として重ねます。
素材に焼き込むと、移籍したときに色が変えられません。

---

## 6. 顔の個体差

**300〜800人が並びます。「みんな同じ顔」がいちばんの失敗です。**

だから、パーツごとに**構造そのものが違う**ものを用意します。

| 部品 | 変えるもの |
| --- | --- |
| 顔の輪郭 | 縦横比・あごの角度・頬骨の張り |
| 目 | 形・開き・まぶた・左右の間隔・傾き |
| 眉 | 太さ・角度・長さ・位置の高さ |
| 鼻 | 鼻梁の高さ・小鼻の広さ・先端の形 |
| 口 | 唇の厚み・幅・口角の向き |
| 耳 | 大きさ・張り出し・耳たぶ |
| あご | 幅・割れ・たるみ |
| 体格 | 肩幅・胸の厚み・全体の量感 |

**やってはいけないこと**：同じ形の色違いを「10種類」と数えること。
髪なら短髪・七三・オールバック・くせ毛・後退…と、**形が違う**ものを並べます。

---

## 7. 年齢

同じ人が年を取るのであって、**別人になってはいけません**（§22）。

| 段階 | 年齢 | 変わるもの |
| --- | --- | --- |
| YOUTH | 〜22 | ひげがほぼ無い |
| PRIME | 23〜27 | 基本の形 |
| MATURE | 28〜31 | ひげが出やすい／表情に厚み |
| VETERAN | 32〜35 | 白髪が出はじめる／生え際が上がる |
| ELDER | 36〜 | 白髪が増える／輪郭がゆるむ |

**変えないもの**：目・鼻・口・耳・骨格。ここを変えると別人になります。

---

## 8. 表情

表情は**ゲームがすでに決めた状態を映すだけ**です（§23）。
表情が状態を決めることは絶対にありません。

```
怪我      → injured
スランプ  → disappointed
疲労      → tired
絶好調    → confident
好調      → focused
優勝・受賞 → happy / celebrating
それ以外  → neutral
```

表情素材は「眉・目・口」だけを描き、顔の上に重ねます。
顔の造作は動かしません。

---

## 9. パーツとして描く

**いちばん大事な決まりです。**

AIに「選手の顔」を描かせてはいけません。**部品だけ**を描かせます。

| 作るもの | 描いてよいもの | 絶対に描いてはいけないもの |
| --- | --- | --- |
| 頭 | 額からあごまでの肌 | 目・眉・鼻・口・耳・髪 |
| 髪 | 前髪・もみあげ・頭頂 | 顔・額の肌・耳 |
| 目 | 左右一組のまぶたと黒目 | 眉・鼻・顔 |
| 眉 | 左右一組の眉 | 目・顔 |
| 鼻 | 鼻だけ | 顔・口 |
| 口 | 閉じた口だけ | 顔・鼻・ひげ |
| 耳 | 左右一組の耳 | 頭・髪 |
| 体 | 肩から胸 | 首・頭・ユニフォーム |

「その素材を、まったく違う10人に重ねても成立するか」で判断します。
成立しないなら、描き込みすぎです。

---

## 10. 置き方

- 必ず**真正面**。横顔・斜めは作らない
- 傾けない
- 背景は**完全に透明**
- 共通キャンバス **1024 × 1280**（`canvas.md`）
- 基準点に合わせる（後処理が直しますが、近いほど品質が上がります）

---

## 11. 禁止（§9）

法律と礼儀の問題なので、例外はありません。

- 実在の選手・監督・有名人に似せる
- 実在球団のロゴ・マーク・ユニフォームの意匠
- 既存ゲーム・アニメのキャラクターに似せる
- 特定のイラストレーターの作風の完全な模倣
- ブランドロゴ・透かし・署名・文字・数字
- 背景・UI・枠・影
- 写真風・3D風
- 低品質なクリップアート
- 奇形・余分な手足・不自然な目
- 特定の国・人種の戯画化（肌の8段階は連続した見本として扱う）
- 未成年に見える造作（17〜45歳の範囲で作る）

機械で見つけられるのは背景と大きさだけです。
文字・ロゴ・似せすぎは **`npm run assets:audit` で人が1枚ずつ見て** 落とします。

---

## 12. 採否

| 点数 | 判定 | 扱い |
| --- | --- | --- |
| 80以上 | APPROVED | 採用してよい |
| 60〜79 | REVIEW | 人が見て決める |
| 59以下 | REJECT | 作り直す |

機械の点数が満点でも、**人の確認が済むまで採用しません**。
点数は「明らかにおかしいものを弾く」ためのもので、良し悪しは測れません。

---

## 13. 迷ったとき

3つの問いに戻ります。

1. **300人並べたときに、同じ顔が2つ出ないか**
2. **他の素材と、線の太さと陰影の段数がそろっているか**
3. **UIの紙面の上に置いて、浮かないか**

3つとも「はい」なら採用です。
1つでも「いいえ」なら、単体でどれだけ良く見えても作り直します。
