# STYLE BIBLE ── 絵柄の決めごと

すべての素材はこの1枚に従います。ここがぶれると、パーツを重ねたときに
「別の絵から切り貼りした顔」になります。**種類が違っても絵柄は同じ**です。

## 1. ひとことで言うと

> 上質な野球雑誌の、インクで刷った選手名鑑。
> 写真ではなく、印刷された肖像。

## 2. 描画スタイル

| 項目 | 決めごと |
| --- | --- |
| 手法 | フラットなベクター調のイラスト。厚塗りにしない |
| 線 | 均一の太さの輪郭線。1024px 基準で 4〜6px |
| 線の色 | 純黒にしない。濃い墨色（#1b1a17 相当） |
| 陰影 | 2階調まで。グラデーションは使わない |
| 質感 | 紙のざらつき・布の織り目は入れない（重ねると濁る） |
| 光源 | 常に左上 45度。すべての素材で同じ |
| 遠近 | なし。正面からの平行投影 |
| 誇張 | 顔の造作はやや大きめ。ただし戯画にはしない |

## 3. 色

ゲーム本体は OKLCH の「紙とインク」を使っています。素材もそこへ寄せます。

| 用途 | 目安 |
| --- | --- |
| 輪郭 | `#1b1a17` |
| 肌 | 8段階。`#f4d9c2` から `#6b4630` までを等間隔に |
| 髪 | 10段階。黒 `#211d1a` / 焦茶 / 茶 / 明茶 / 赤茶 / 金 / 白髪3段 / 銀 |
| ユニフォーム地 | 生成りの白 `#f2efe6`（**球団色では塗らない**） |
| 影 | 地の色に墨を 12% 混ぜた色 |

**球団色は素材に焼き込まない。** 球団色はゲーム側が細い線として重ねます。
球団色で塗った素材を入れると、移籍したときに色が変えられなくなります。

## 4. 向き・構図

- すべて**真正面**。横顔・斜めは作らない
- 首から上は `head` の基準枠に必ず収める
- 肩から下は `body` の基準枠に必ず収める
- パーツ単体で見ると「宙に浮いた部品」に見えるのが正解

## 5. 背景

**完全な透明（アルファ）。** 白背景も、床の影も、枠線も入れません。
背景を消し忘れた素材は `npm run assets:validate` が落とします。

## 6. 人物の扱い

- 実在の選手・監督・有名人に似せない
- 実在球団のロゴ・マーク・ユニフォームの意匠を使わない
- 既存ゲームのキャラクターに似せない
- 特定の国・人種を戯画化しない。肌の8段階は連続した見本として扱う
- 年齢は 17〜45 歳の範囲。未成年に見える造作は作らない

## 7. パーツを重ねる前提

各パーツは**単独で完結した絵**として描き、隣のパーツを描き込みません。

- `head` に目・鼻・口を描かない（輪郭と耳の付け根まで）
- `hair` に額の肌を描かない
- `eyes` に眉を描かない
- `body` に首を描かない（`neck` が別にある）
- `uniform` に体の肉付きを描かない

重なりの順番は `config/visual-assets.json` の `layer` が決めます。

## 8. 迷ったら

「この素材を、まったく違う10人の顔に重ねても成立するか」で判断します。
成立しないなら、それは描き込みすぎです。
